# A+ Credit Restoration — Deployment Package

This package contains the production source for the redesigned A+ Credit Restoration website.

## Included

- Executive A+ Techucation visual system
- Responsive homepage and navigation
- Credit education and service sections
- Consumer-rights and compliance disclosures
- Official federal and authorized resource links
- Credit-utilization and debt-payoff calculators
- Zoom consultation links
- ATechSpot corporate cross-linking

## Production commands

```bash
npm ci
npm run build
```

The verified production build produces the deployment artifact in `dist/`.

## Recommended domain

`credit.atechspot.com`

## Pre-launch checklist

- Review all services, prices, disclosures, agreements, and payment timing with qualified Texas counsel.
- Confirm the Zoom scheduling URL and business contact details.
- Test every official-resource link and calculator.
- Keep the existing credit website live until the new custom-domain connection and SSL certificate are active.
- Do not remove the no-guarantee, self-dispute, privacy, or consumer-rights disclosures.
